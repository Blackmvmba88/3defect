# Expedition Rover

Primera interpretación 3D del todoterreno de expedición de la referencia: carrocería coral, llantas grandes, winch frontal, refacción y equipaje sobre el techo.

- `Expedition_Rover.blend`: fuente editable.
- `Expedition_Rover.glb`: exportación del vehículo sin piso, cámara ni iluminación.
- `Expedition_Rover.png`: render de estudio.
- `build_rover.py`: generador para Blender; produce los tres archivos anteriores.

![Render](Expedition_Rover.png)

Pendiente: acercar la silueta a la ilustración y agregar desgaste y calcomanías. Es un modelo visual; no incluye rig, física de conducción ni preparación para impresión 3D.
