# P911_REF_001 — reference-matched widebody sports car

This profile captures the supplied red 3/4-view reference as a parametric vehicle, not as a one-off static mesh.

## Modeling target

Priority order:

1. silhouette
2. wheelbase / wheel diameter
3. stance and track width
4. cabin envelope
5. front/rear fender mass
6. front fascia
7. rear wing
8. lights, glass and trim

A render with flat black material should match the reference silhouette before fine details are added.

## Why the values are a seed

The source is a single perspective image, not an orthographic blueprint. Therefore the current dimensions are calibrated starting values. Side, front and rear orthographic references can later be used to tighten the fit.

## Master behavior

reference_match controls the morph:

- 0.0 = realistic baseline
- 0.5 = halfway
- 1.0 = supplied reference look

The profile also exposes independent controls for width exaggeration, roof compression, wheel exaggeration, fender exaggeration, stance and front/rear visual weight.

## Normalized visual constraints

The model stores ratios with wheelbase normalized to 1.0. This allows comparison against an image independent of pixel dimensions.

Current seed:

- wheel diameter: 0.285
- total height: 0.545
- hood height: 0.285
- beltline height: 0.390
- roof start: 0.295
- roof length: 0.465

## Semantic part graph

The vehicle is divided into stable groups: BODY, FENDERS, FRONT, LIGHTS, WINDOWS, WHEELS and AERO.

Future Blender scripts should create collections/objects using these names so the model remains editable and automation-friendly.
